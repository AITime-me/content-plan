# AI MY TIME — контент-план на 14 дней

Самостоятельный статичный конструктор промпта для контент-плана.

**Лендинг:** https://aitime-me.github.io/content-plan/

Заполните вводные, выберите цели, частоту, форматы и Stories, скопируйте промпт в свою нейросеть. Без регистрации, платного API и передачи вводных на сервер.

## Сборка

Исходники находятся в `source/`. Авторский промпт — `source/prompt.txt`.

```sh
python3 source/build.py
```

Сборка создаёт самостоятельный `index.html` в корне. Для публикации используется GitHub Pages, ветка `main`, корень репозитория. `og-cover.jpg` — обложка ссылки.
